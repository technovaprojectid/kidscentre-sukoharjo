# Kids Centre Sukoharjo Web Application

Repositori ini berisi kode sumber untuk website resmi **Kids Centre Sukoharjo** (`kidscentre-sukoharjo`), sebuah platform pusat layanan dan informasi anak yang dikembangkan oleh [TechNova Project](https://github.com/technovaprojectid).

---

## 🚀 Fitur Utama

* **Informasi Layanan:** Menampilkan berbagai program, fasilitas, dan aktivitas yang tersedia di Kids Centre Sukoharjo.
* **Pendaftaran & Kontak:** Memudahkan orang tua untuk mendapatkan informasi pendaftaran serta menghubungi pihak pusat.
* **Desain Responsif:** Tampilan yang ramah pengguna (user-friendly) dan optimal di berbagai perangkat (desktop, tablet, smartphone).

## ⚙️ Cara Menjalankan Proyek (Development)

1. Lakukan kloning pada repositori ini:
```bash
git clone https://github.com/technovaprojectid/kidscentre-sukoharjo.git

```


2. Buka direktori proyek:
```bash
cd kidscentre-sukoharjo

```


3. Jalankan atau buka file `index.html` menggunakan browser pilihan Anda, atau gunakan *Live Server* pada teks editor (seperti VS Code).
